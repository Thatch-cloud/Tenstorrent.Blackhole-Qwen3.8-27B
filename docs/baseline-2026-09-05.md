## Cache observations

4709 successful metrics scrapes, no scrape errors. KV usage ranged from zero while
idle to fraction `0.12489327966825226` (12.4893%). Of 4065 samples reporting running
requests, none reported zero KV occupancy. No preemptions were observed. Thus the
historic active-zero issue did not recur in this run; this does not prove every
cache lifecycle, scheduler metric or dashboard integration is correct.

## Scope and next comparison

Network-isolated container-local endpoint, host sampling, `logprobs=1` to establish
token accounting. Logprobs add work and force host sampling on TP2, so these results
are not an uncontaminated comparison against device sampling or the historical
no-logprobs 36 ms probe. Capture token-ID streaming support and test without
logprobs next. Engine commit timestamps and gateway overhead remain unavailable;
these client estimates cannot certify the 200 committed-token/s target.

All raw reports and server logs are retained as CI artifacts and downloaded locally,
not committed. Run `scripts/ci/summarize-baseline.py` on the artifact directory to
reproduce the table and cache observations.
