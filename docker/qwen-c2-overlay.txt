# Every repo file the C2 serving image (docker/qwen-c2-serving.Dockerfile) lays over its P8 base.
#
# This is the ONE list. Nothing else names these files:
#   - scripts/ci/c2_overlay.py stage   copies each SOURCE into the build context (the CI build step
#                                       in .github/workflows/qwen-c2-serving.yml, and a hand build);
#   - scripts/ci/c2_overlay.py install copies each into the image (the Dockerfile), and runs every
#                                       overlaid scripts/ci/test_*.py inside it;
#   - scripts/ci/build-c2-serving-image.sh checks the staged context against it, and
#     scripts/ci/c2_image_provenance.py checks every DESTINATION's sha256 in the built image;
#   - scripts/ci/test_c2_image_overlay.py fails when a file the image holds differs from HEAD but is
#     named neither here nor in the P8 copy lists (the P8 base commit's), unless it is KNOWN_STALE.
#
# The image's fast-path tree has three delivery routes, and a file NOT named here ships at the
# version its route froze (memory serving-image-bundle-provenance):
#   1. the bundle archive (commit 77d6995a): /experiment-scripts and /speculative-decoding;
#   2. the P8 copy lists (docker/qwen-fast-serving.Dockerfile + qwen-fast-serving-image.yml) at the
#      P8 base's commit (the Dockerfile's ARG BASE, qwen-fast-serving:ci-<commit>);
#   3. this list, at the commit the C2 image is built from.
#
# Format: SOURCE [DESTINATION ...]
#   SOURCE is repo-relative, under scripts/ci/ or speculative-decoding/harness/.
#   With no DESTINATION a file replaces the base image's copy of it:
#     scripts/ci/<file>                    -> /experiment-scripts/ci/<file>
#     speculative-decoding/harness/<file>  -> /speculative-decoding/harness/<file>
#   Listed DESTINATIONs replace that default (repeat it to keep it). @purelib/ is python's
#   site-packages directory in the image.
#
# Never list frozen_combined_runtime.py: the native cache pins its bytes
# (serving_native_install.py:57). Change its callers instead.
