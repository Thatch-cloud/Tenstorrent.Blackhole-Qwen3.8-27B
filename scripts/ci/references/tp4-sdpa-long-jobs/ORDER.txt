# The order of the tp4/sdpa-long window, one template per line: <template name without .env> <stop|optional> <image tag> <estimated minutes>.
# stop: the window halts at the first failure of this job. optional: a failure or a skip does not stop the window (its product is data).
# Image: tp4-next-3a is a PLACEHOLDER for a four-card image on the rig that carries the K64j op graft the sweep needs (step P1 below confirms it before A0). NO build job (B0) is needed: the
# sweep harness mounts its scripts from the checkout, mounts no graft and needs no weights, and nothing in this window serves the new flag.
# Minutes: runner time for ONE run of the job.
#
# THE LANE. Long-context SDPA bandwidth at TP4 (design: per-chip decode attention reads K and V at about 150 GB/s against about 405 GB/s of
# DRAM; at a 262,144-token window attention is the largest term of the round). Q1 is the one-card sweep that times every candidate
# configuration against the served call and byte-compares each with it; it applies nothing. Its arms are the values of QWEN_FAST_TP4_SDPA
# (scripts/ci/sdpa_long_tp.py): served, grid8x4, grid8x10, grid4x8 (servable worker-grid changes), grid11x4 (servable; the CONTROL: the served placement, only the idle-core and
# dispatch set differs), multi, rowsplit, ra (measured only; the risky ones run in a second pass after every safe case). A winner must beat served in every paired round and by 2% on average.
#
# DRIVER STEP BEFORE THE WINDOW (production serving, no card opened):
#   P1  confirm the image: QUAL_CARD=<card M board id> ALLOW_SERVING_CARD=1 IMAGE_CHECK_ONLY=1 IMAGE_TAG=tp4-next-3a bash optimisation/ttnn-op/sdpa_tp4_long/run_card_m.sh on the rig. It names the board like the cardm step (QUAL_CARD and ALLOW_SERVING_CARD=1, because the
#       canonical selection block runs first) but opens no device, and exits 0 only when the local image exists and every _ttnncpp.so in it is the pinned K64j graft. The tag in the templates is a PLACEHOLDER: if the check
#       fails, name the right tag in BOTH templates (A0 and Q1, and IMAGE_TAG in Q1's C2_CARDM_ENV) BEFORE A0 runs; never start A0 on an unchecked tag (A0 takes production down).
# PRODUCTION IS LIVE ON THE CARDS when the window opens: A0 (agentstop, unserve; no status action, the driver would flag production's container as stale) is the first job and
# the only one that takes it down. Q1 then runs on card M alone (the cardm step; no reset needed).
# WHAT COMES AFTER (a later window, not this order): when Q1's winners are read, edit the one value of the profile c2-packed-tp4-best-sdpa
# (QWEN_FAST_TP4_SDPA, a placeholder "served" today) to the winner, build an image from the pushed tp4/sdpa-long commit (the flag's module is new, and
# tp4-next-3a does not carry it), run the audited matrix on it, the 5/5 hang gates, then ABAB timed pairs against c2-packed-tp4-best-strace at
# 4 x 4k, 4 x 32k and 4 x 131k, judged PAIRED per round, never by an unpaired median. Only a name that Q1 found exact (differing_rows 0 in every
# case of its kind) and that the flag accepts as servable can be tried; the engaged line "[PINDIAG] tp4 sdpa engaged" must appear in the engine log.
# HAND-BACK IS THE DRIVER'S, AFTER Q1 AND EVEN WHEN Q1 FAILED OR HUNG: no job of this pack brings the node agent back (a hand-back job in the order would put production back mid-programme
# if a driver ran the order as written). The driver resets all four cards, re-measures the fabric (it must pass before production serves), starts the node agent, and an owner
# /deploy places today's production recipe (and anything new). This order never includes a deploy, a :latest retag or a placement call.
# THE LONG-CONTEXT TWIN: c2-packed-tp4-best-sdpa carries the 131,328-token limits; the 262,144-token follow-up window needs a 262k twin of it.
# Never cancel a running card job (root-owned logs): the next job's reset heals the cards.
# Durations (estimate, wall clock): A0 10 min; Q1 40-50 (container timeout 50). Whole window: about 1 h, then the driver's hand-back.
A0-agentstop-unserve stop tp4-next-3a 10
Q1-sdpa-long-sweep optional tp4-next-3a 50
