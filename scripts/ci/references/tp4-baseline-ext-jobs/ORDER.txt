It runs ONLY on today's production ENGINE (the base image under production's thin layer; SR10 replays the thin layer itself) and the production profile family. Nothing here builds an image, moves :latest or places a model. One line per job:
# <template name without .env> <class> <image tag> <estimated minutes> <tag> <box minutes>.
# CLASSES. stop: the extension halts at its first failure (the hand-back still runs). soft: data; a failure or a skip does not stop it. opt: OPTIONAL, run only when the first window did not run it AND the clock allows. hand: the hand-back, always runs. drv: a DRIVER or OPERATOR step with no template and no tag (LM: the links re-measure workflow; TICK: the wait for the topology to publish the new links; DEPLOY-and-engine-load: the operator's release step and the engine load).
# VALUE ORDER (the jobs the production go-live skipped, most valuable first): A0X0 (the cards, no status step), H1 and H2 (the production hang shapes), SR10 (the platform replay of the production thin layer), C16-CTL (churn at eight seats), E1-CTL (eager exactness to 262k), G0 (agent turns, timed), T0 (the timed production-bytes round), then the V5 block (R4 V1a V1b) ONLY if the first window's verdicts show it did not run. The first window's own P1a-CTL, P1b-CTL, L8-CTL and PROF-CTL are NOT repeated here: the owner reads their verdicts and decides.
# MINUTES are MEASURED-BASIS ESTIMATES (the fast-window plan's measured job times): attach 2-5 min, reset 0.7-4.4 min, the five-shape smoke jobs 9-18 min, the hang jobs 11.5-16.1 min, a G arm 16.5 min, SR10 about 25 min, a T job 25-31 min, E1 60-153 min, C16 20-35 min; V1a and V1b are the owner's 30 and 90; A0X0 is a stop, a rescan and a reset (10).
# BOXES: for a gate or prefix job the docker timeout of its arms plus the per-arm overhead (c2_prefix_gate PLAN_ARMS, c2_serving_gate plan_arms: computed by test_tp4_baseline_ext_window from those tables); for a card-M job the workflow's step timeout (140 min) plus 5 minutes of set-up; for a smoke or replay job TWICE the measured worst (H1 and H2 35, T0 65) and for SR10 120 (its own thinking-budget smoke is up to 90 min). The workflow's own step caps (smoke 210 min, replay 180 min) are higher: a started job is never cancelled, so a hung smoke can pass its box (see README). A '-' box is a short step with no gate timeout.
# THE HAND-BACK IS 95 MIN: the reset 15 + the links re-measure 15 + the wait for the topology to publish the new links up to 18 + the agent start Z 32 + the release step and the engine load 15.
# CORE = A0X0 H1 H2 SR10 C16-CTL E1-CTL G0 T0 = 257 min = 4.3 h of jobs and 352 min = 5.9 h with the hand-back. The V5 block (R4 V1a V1b) adds 135 min by estimate.
# THE CLOCK RULE (the private driver, a WALL-CLOCK TARGET and not an elapsed budget): the TARGET is 19:45Z. Before each job, with NOW the wall clock and HB the hand-back (95): the job starts when NOW + its BOX + HB <= 19:45Z (a job with no box uses its estimate); else it is SKIPPED-TIME. The opt block must fit whole: R4 15 + V1a 145 + V1b 145 = 305 by box. Nothing is ever cancelled. ADMIT_BASIS=est (the owner's choice) admits by the estimate instead of the box. The driver does not start before the first window's hand-back reached READY FOR /deploy (its START GATE).
# STOP-EARLY: the driver reads a file named STOP in its results directory before every job: it skips the rest and runs the hand-back.
# TAGS: experiment/c2-serving-v601 to v615, hardware-allowlisted and never pushed (the driver's preflight checks the remote). The k-th job that has a tag takes the k-th tag of v601 upward; the reserve v614-v615 is for a retried ZR or Z. The first window uses v538-v557 and another plan may use v558 upward: this block stays inside v601-v615.
