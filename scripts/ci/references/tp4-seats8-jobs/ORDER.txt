# <template name without .env> <stop|optional> <image tag> <estimated minutes>.
# stop: the window halts at the first failure of this job. optional: a failure or a skip does not stop the window (its product is data).
# Image: the tag of the tt-vllm image the job serves (tp4-seats8, prebuilt by a build-only job while production served; no job here builds).
# Minutes: runner time for ONE run of the job, a quad reset (1-3 min) included.
# PRODUCTION IS LIVE ON THE CARDS when the window opens: the placement is removed through the admin API first (the user's go-ahead and an admin
# token), then S8-0 unserves (the only job that does). The window closes with H8, which runs even when a stop job halts the window, and re-places
# TODAY'S PRODUCTION RECIPE (the image and profile c2-packed-tp4 that served before; the :latest tag unchanged), never a gate arm.
# TWO STAGES, the first the cheapest kill signals:
# (a) PROBE, about 4 hours, first: S8-0 production profile on the new image with the seat flag OFF (nothing may differ); S8-1 the first attach
# of eight seats on the audited gate profile (blocks=2, block B compiles nothing after A's capture, DRAM after attach about 22.7 to 23.0 GB per chip,
# audited concurrent8_code_equal with zero mismatches); S8-6 memory at 8 live (kill: free below 3 GB per chip) right after it; then S8-7a and S8-7b ONE paired timing (kill: the 8-live round above

# hours) is not run, and H8 hands the cards back.
# (b) QUALIFICATION: S8-2a the S3a matrix at eight users on the audited gate profile and S8-2b on the traffic profile (the M7 pattern); S8-3a to
# S8-3e the audits-off hang shapes on c2-packed-tp4-8-diag-strace (stall watch, handle log and guard), each after its own reset: five consecutive
# completions, and there is NO qualified hang fallback at 8 seats; S8-4 staggered and S8-5 churn of 16 sessions over 8 seats; S8-7c and S8-7d the
